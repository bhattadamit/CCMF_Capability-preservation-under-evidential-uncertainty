# Conversion Weekends: not included

The request to include a package for the Conversion Weekends paper could not be met with real content. In the session in which this package was built:
- no results, analysis scripts, event list or data files for that paper were provided or existed;
- the public complaint data source (CFPB) was not reachable from the build environment.
Producing derived "results" for it would mean inventing them, so none are included.

To build a proper package, supply: the list of bank-merger conversion events (acquirer, target, conversion date), the extracted complaint data or the exact query used, the analysis code or specification (event window, controls, model), and the results tables. A package of the same form as this one (code, data, derived tables, README, checksums, rerun check) can then be produced and verified.
